🤖 讓 App 自己挑（最省事）

把這段貼到你 App 的 Claude Code 對話，它會看過全部技能和你的程式，自己挑用得到的裝好。

一次裝一組

勾選適合的組合，下面的指令會自動更新。防禦健檢技能每次都會一起裝。

怎麼挑？
  • core：每個 App 都該裝。
  • pwa：手機網頁、有 manifest.json 或 service worker。
  • actions：有 .github/workflows 資料夾。
  • backend：有資料庫或 API 伺服器。
  • security：有登入、金鑰、使用者資料。
  • stock：股票相關 App 或要分析個股（含台股資料收集工具）。
  • agent：App 裡有會自己查資料、做事的 AI（AI Agent）；通常跟 ai 一起裝。
  • 不確定就只勾 core，指令裡已經請 Claude 幫你判斷要不要加。

瀏覽全部技能

可以單個複製，也可以勾選多個後從底部一次複製。要在 claude.ai 網頁版用，按技能下面的「下載 ZIP」再上傳（步驟見「說明」分頁）。

健檢與更新

🔍 我的 App 該裝哪些技能？（只建議、不安裝）

選你的 App，或選最後一項貼 GitHub 網址。

X-Ray 不用開 Claude、幾秒就有建議，但只看檔案結構；Claude 會讀程式內容，比較準。


下面兩個在已經裝過技能的 App 裡使用。

防禦準則健檢

把技能更新到最新版

怎麼用

  1. 在「組合安裝」或「瀏覽技能」挑好，按「複製」。
  2. 打開你另一個 App 的 Claude Code 對話（claude.ai/code），貼上送出。
  3. Claude 會把技能複製進那個 repo 的 .claude/skills/ 並 commit，之後每次對話都會自動用到。
為什麼技能內容是英文？會不會影響效果？

技能本體維持英文：Claude 讀英文指令最精準，也方便日後同步上游更新。回覆語言由各 App 的 CLAUDE.md 決定（例如「一律用繁體中文」），所以你看到的回答仍是中文。這個網頁上的中文說明只是方便你挑選。

「給 Claude 的指令」和「終端機指令」差在哪？

給 Claude 的指令是一段中文，貼到對話裡讓 Claude 幫你做完全部步驟（推薦）。終端機指令是給會自己下指令的人用的。

在 claude.ai 網頁版用技能：下載 ZIP 上傳
  1. 在「瀏覽技能」找到技能，按「下載 ZIP」，iPhone 會存到「檔案」App 的「下載項目」。
  2. 先確認 claude.ai 的 Settings → Capabilities 已開啟「Code execution and file creation」（技能要靠它才能跑）。
  3. 到 Customize → Skills，按「＋」→「Create skill」→「Upload a skill」，選剛下載的 ZIP。
  4. 上傳後在技能清單把它打開。上傳的技能只有你自己看得到。

claude.ai 規定技能描述最多 200 字元，所以 ZIP 裡的描述是縮短版，完整原文放在 SKILL.md 內文第一段。要用到 GitHub 或本機程式的技能（例如 app-bootstrap）在 claude.ai 不一定能用。 操作路徑照 Claude 官方說明（2026-10-18 查證）；介面改版時以官方說明為準。

加到 iPhone 主畫面

在 Safari 按「分享」→「加入主畫面」，之後就像 App 一樣打開。網頁有新版時會自動重新載入。

# 自製技能對照測試（有技能／沒技能）

測試日：2026-10-18。工具：`ops/skill_eval.py`（`selftest` 離線測評分規則；`run` 會用掉 Claude 用量）。

## 怎麼測

- 三個題目，都是平常會講的一句話：
  1. **台股**：寫一支每天抓上市收盤價、存 SQLite 的腳本，附離線自我測試。
  2. **App 健檢**：一個故意埋了 10 個問題的小 App，請它列出問題、先不要改程式。
  3. **AI 自動挑模型**：替 Cloudflare Worker 加 Gemini 摘要功能，附離線測試。
- 每題建兩份一模一樣的練習 App，都放 `CLAUDE.template.md` 當工作守則（跟真的 App 一樣）。
  只差有沒有把技能裝進 `.claude/skills/`。
- 用 `claude -p`（Claude Code 預設模型）各跑 2 次，共 12 次。
  - 禁止上網搜尋；跑自我測試時把網路切斷。
- 評分用程式檢查關鍵做法，不用 AI 打分（避免評審偏心）。例如有沒有用官方 OpenAPI、有沒有開 WAL、有沒有寫死模型名稱、測試有沒有過。
- 花費：12 次共約 13 分鐘；工具回報的等值 API 費用約 US$2.4。

## 結果

| 題目 | 有技能（平均） | 沒技能（平均） | 差在哪 |
|---|---|---|---|
| 台股資料 | 5.5／6 | 3.5／6 | 沒技能時都用證交所網站的 `MI_INDEX`，不是官方 OpenAPI；SQLite 都沒開 WAL |
| App 健檢 | 11／11 | 10／11 | 沒技能時兩次都漏了「SQLite 沒開 WAL」；其他 9 項沒技能也抓得到（有些是工作守則寫的，有些是常識） |
| AI 自動挑模型 | 5／6 | 4／6 | 沒技能時也沒寫死模型（工作守則有寫），但自己寫了一套「問 API 挑最新 flash」；有技能時改用共用模組、只寫等級 |

有技能的 6 次都有實際用到技能；沒技能的 6 次都沒有（從執行紀錄判斷）。

## 看出來的事

- **有用的是 AI 不知道的東西**：官方資料來源、工作守則沒寫到的規則（例如 SQLite 要開 WAL）、現成腳本。
- **工作守則（CLAUDE.md）已經擋掉很多問題**：沒技能時也沒有寫死模型名稱、有 noindex 提醒。
  技能補的是「怎麼做才標準」，例如用同一套模組、每個 App 一樣，壞了只修一處。
- **測試抓到技能本身的漏洞**：兩邊都沒有請求逾時，追下去發現 `ai-model-router` 的 JavaScript 模組
  沒有逾時（Python 版有 60 秒）。已補上 60 秒逾時並加自我測試（沒修之前，測試確認會失敗）。
- 每題只跑 2 次，數字會有波動，只能當方向參考，不是精確的分數。

## 怎麼重跑

```bash
python3 ops/skill_eval.py selftest                    # 不花用量
python3 ops/skill_eval.py run --out /tmp/skill-eval   # 會用掉 Claude 用量，約十幾分鐘
python3 ops/skill_eval.py grade /tmp/skill-eval       # 重新評分
```

要加新題目：在 `CASES` 加一個（題目、練習 App 的檔案、評分函式），並在 `selftest` 補「什麼都沒做要全部不過」的測試。

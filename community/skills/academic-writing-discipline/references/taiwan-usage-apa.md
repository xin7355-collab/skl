# 台灣學術用語、APA 7 中文化、連接詞與標點

## 一、台灣學術用語

台灣的碩論應依學科、系所與投稿單位的慣例統一用語。混用不同地區的術語會增加理解成本，但**用語差異本身不能證明文字由 AI 產生**。

### 1. 一般學術用語

| 台灣用法 | 大陸用法 | 英文 |
|---|---|---|
| 資料 | 數據 | data |
| 透過 | 通過 | through / via |
| 探討 | 研究 / 表明 | explore / investigate |
| 受試者 / 填答者 / 研究參與者 | 被試 | participant / respondent |
| 資訊 | 信息 | information |
| 軟體 / 硬體 | 軟件 / 硬件 | software / hardware |
| 網路 | 網絡 / 互聯網 | network / internet |
| 程式 | 程序 | program |
| 素養 | 素質 | literacy / competency |
| 母群體 / 母體 | 總體 | population |
| 架構 | 框架 | framework |
| 建構 | 構建 | construct (v.) |

### 3. 研究方法描述用語

## 二、APA 7 中文化慣例

### 1. 內文引用

| 情境 | 格式 | 範例 |
|---|---|---|
| 中文作者，敘述引用 | 作者全名（年份） | 張三（2024）指出…… |
| 中文作者，括號引用 | （作者全名，年份） | （張三，2024） |
| 英文作者，敘述引用 | 姓氏（年份） | Davis（1989）提出…… |
| 英文作者，括號引用 | （姓氏, 年份） | （Davis, 1989） |
| 英文 2 位作者 | 姓氏與姓氏（年份） | Hair 與 Risher（2019） |
| 英文 3 位以上作者 | 第一作者等人（年份） | Venkatesh 等人（2012） |
| 同作者同年多篇 | 加 a, b | （Morgan et al., 2024a, 2024b） |
| 第一作者同姓、名字縮寫不同（年份不同也算） | 每次引用都加第一作者名字縮寫（APA 7 第 8.20 節） | A. Taylor（2023）、R. Taylor 等人（2023） |
| 第一作者相同、同年，作者群不同（縮成「等人」後看起來一樣） | 列出足以區分的作者，其餘才縮成「等人」，每次引用都這樣寫（APA 7 第 8.18 節） | Kapoor、Bloom、Montez 等人（2017）與 Kapoor、Bloom、Zucker 等人（2017） |
| 同括號多篇 | 分號隔開，依年份排列 | （Davis, 1989; Venkatesh et al., 2012） |

注意：
- 台灣用「**等人**」，中文行文中不用「等」或「et al.」。
- 英文作者之間用中文「**與**」，不用 "&" 或 "and"。
- 括號引用時，英文文獻用半形逗號和分號，中文文獻用全形逗號。
- 同姓的情況在書目管理軟體建檔時就要看出來：citekey 出現同姓同年，或同姓不同名字縮寫，寫正文時照上表區分。

### 2. 參考文獻格式

中文文獻：
```
張三（2024）。論文寫作的技藝。聯經出版。
張三、李四與王五（2024）。文章標題。期刊名稱，卷（期），頁碼–頁碼。
```

英文文獻：
```
Davis, F. D. (1989). Perceived usefulness, perceived ease of use, and user acceptance
    of information technology. MIS Quarterly, 13(3), 319–340.
```

中文文獻注意事項：
- 作者之間用頓號「、」，最後兩位用「與」。
- 書名、期刊名用斜體。
- 年份用西元，置於括號內。
- 頁碼用半形連字號 `–`（en dash），不用全形 `—`。
- 同一括號中多篇：中文在前按筆畫排序，英文在後按字母排序，用分號隔開。
- 參考文獻清單：系所沒有另外規定時，可比照同一括號多篇的排序，中文文獻在前、依作者姓氏筆畫，英文文獻在後、依字母。

### 3. APA 7 與 APA 6 的主要差異

| 項目 | APA 6 | APA 7 |
|---|---|---|
| 三位以上作者首次引用 | 列出所有作者 | 首次起即用「第一作者等人」 |
| DOI 格式 | doi:10.xxx | https://doi.org/10.xxx |
| 出版地 | 需列出 | 不需列出 |
| "Retrieved from" | 需要 | 不需要（直接附 URL） |
| 期刊卷期 | 卷號粗體 | 卷號斜體，期號不斜體 |

**各系所可能有自己的格式規定，一律以系所公告為準。**

## 三、連接詞與標點慣例

### 1. 依功能分類的連接詞

- **因果／邏輯推進**：因此、故、是以、由於……因此……、鑑於此、有鑑於此
- **補充／遞進**：此外、另外、再者、除此之外、進而
- **轉折／對比**：然而、但是、不過、相反地、儘管如此、惟
- **時序／列舉**：首先……其次……再者……最後、第一……第二……、一方面……另一方面……
- **收束／歸納**：整體而言、根據上述分析、由此可知、歸納上述

### 2. 應避免或節制的連接詞

| 應避免 | 改成 |
|---|---|
| 綜上所述 | 多半可刪，或改「歸納上述」 |
| 值得注意的是 | 全篇最多 2 次 |
| 換言之 / 換句話說 | 改冒號，或直接刪除 |
| 「首先，」「其次，」連用超過三段 | 改用其他結構 |
| 一方面……另一方面…… 每段都用 | 換句型 |

### 3. 標點慣例

| 項目 | 台灣用法 | 注意 |
|---|---|---|
| 引號 | 「」（單）、『』（雙） | 不用 " " |
| 書名號 | 《》（書籍）、〈〉（篇章） | |
| 句號 | 。 | 中文句子不用 . 結尾 |
| 逗號 | ，（全形） | 中文行文不用半形逗號 |
| 分號 | ；（全形） | 括號引用中分隔文獻時用半形 |
| 冒號 | ：（全形） | |
| 破折號 | —— 或 ── | 學術寫作盡量少用，改逗號或括號 |
| 數字 | 阿拉伯數字搭配中文量詞 | 「300 份」「7 點量表」「5 條假說」 |
